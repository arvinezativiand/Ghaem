# Add Property Feature

Description: Implements or modifies functionality related to real-estate properties while preserving domain rules, filtering, SEO, image handling, and MVC architecture.

## Steps

1. Inspect Property, PropertyImage, enums, services, ViewModels, controllers, and existing Views.
2. Determine whether the change affects:
   - Domain
   - Application
   - Infrastructure
   - Web
   - Tests
3. Apply the appropriate project Rules and Skills.
4. Preserve the distinction between Sale and Rent.
5. Preserve property status behavior.
6. Preserve image-storage security.
7. Preserve SEO-friendly property URLs.
8. Preserve server-side filtering and pagination.
9. Add or update tests.
10. Build the solution.
11. Run relevant tests.
12. Verify the public property detail URL.
13. Verify the admin behavior.
14. Report the final changes and verification results.
