# Implement Feature

Description: Implement a project feature safely while respecting the architecture, testing, and verification rules.

## Steps

1. Understand the requested feature.
2. Inspect the existing project structure.
3. Read only the Rules and Skills relevant to the feature.
4. Identify affected layers.
5. Create a short implementation plan.
6. Implement the Domain changes if required.
7. Implement Application changes.
8. Implement Infrastructure changes if required.
9. Implement MVC/Web changes if required.
10. Add or update tests.
11. Run formatting or standard project checks if available.
12. Build the solution.
13. Run tests.
14. Review the implementation for unnecessary complexity.
15. Verify authorization and validation.
16. Report exactly what changed and what was verified.

## Important

Do not rewrite unrelated code.

Do not introduce new architectural patterns without justification.

Do not mark the task complete if the solution does not build.
