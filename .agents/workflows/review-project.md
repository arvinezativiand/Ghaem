# Review Project

Description: Performs a structured review of the real-estate application for correctness, architecture, security, performance, maintainability, SEO, and UI issues.

## Steps

1. Inspect the solution structure.
2. Check project dependencies and dependency direction.
3. Check Domain purity.
4. Check Application responsibilities.
5. Check Infrastructure boundaries.
6. Check MVC controller complexity.
7. Check ViewModel usage and over-posting risks.
8. Check authentication and authorization.
9. Check anti-forgery protection.
10. Check image upload security.
11. Check SQL and EF Core query efficiency.
12. Check property filtering and pagination.
13. Check Sale/Rent validation.
14. Check Property Status handling.
15. Check SEO metadata and property URLs.
16. Check RTL and responsive UI.
17. Run build.
18. Run tests.
19. Report findings grouped by severity:
   - Critical
   - High
   - Medium
   - Low
20. Do not modify code unless explicitly asked to fix the findings.
